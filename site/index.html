Your servers, finally organized.

rdpNext is a fast, modern remote desktop and SSH client for macOS and Windows. Every server lives in one tidy sidebar, every session opens in its own tab.

Download View on GitHub
macOS (Apple Silicon) and Windows (x64)
Sidebar

Every server, one click away.

All your connections sit in a single sidebar, grouped in folders and tagged with a color. Find any of them in a second.

  • Type to filter, press Enter to connect to the first match.
  • Single click selects, double click connects.
  • Drag and drop to reorder or move between folders.
  • Right click to edit, duplicate or delete.
  • A green dot shows which servers are connected right now.
Sessions

RDP and SSH, side by side in tabs.

Windows servers, Linux desktops over xrdp and SSH terminals all open as tabs in the same window. Switch between them like browser tabs.

  • The remote desktop fits the window and follows it as you resize.
  • Go full screen for any session and come back to its tab.
  • Copy and paste text and files between your computer and the server.
  • Remote audio plays on this computer.
  • Built-in SSH terminal with password or private key sign in.
Editing

No dialogs. Just a tab.

Adding or editing a server opens a clean form in its own tab, so your sessions stay right where they are.

  • Pick Windows, SSH or Linux and a color.
  • Set the user, password and domain once on a folder; every server inside inherits them.
  • Override any of them per server when you need to.
Import

Coming from mRemoteNG? Bring everything.

Point rdpNext at your confCons.xml and your RDP and SSH connections arrive with their folders and passwords. Nothing to retype.

  • Works with files protected by an mRemoteNG master password.
  • Entries you already have are not added twice.
  • Export your whole list to a single file and import it on another machine (passwords are left out of the file).
Security

Your passwords stay in your keychain.

rdpNext never writes passwords into its own files. They live in the macOS Keychain or the Windows Credential Manager.

  • Unknown server certificates are shown before you connect, fingerprint included.
  • Trust once; you are asked again only if the certificate changes.
  • SSH host keys are verified and remembered the same way.
